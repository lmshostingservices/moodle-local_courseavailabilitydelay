# local_courseavailabilitydelay

## Summary

Delay when enrolled courses appear on a student's My Courses dashboard.

## Description

Delay when enrolled courses appear on a student's My Courses dashboard. Configure a delay period per course — students only see the course after N days since enrolment, or after a fixed unlock date. Supports per-user overrides and bulk CSV import. 1,000 AI credits to unlock.

## Current Release

Version 1.0.9 republishes the reviewed authoritative source under a new immutable tag because the historical tag contained a different source tree. There are no functional changes in this release.
